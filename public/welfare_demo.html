정부 복지 사이트 연결 데모

실제 복지로(bokjiro.go.kr) 사이트로 이동하는 버튼과, 공공데이터포털 복지 API를 실시간으로 호출하는 화면을 함께 담았습니다. 아래 두 기능은 모의(mock) 데이터가 아니라 실제 엔드포인트를 향합니다.

실제 복지로 사이트로 이동 API 키 불필요

버튼을 누르면 새 창에서 정부가 운영하는 실제 복지로 사이트가 그대로 열립니다.

※ 개별 서비스(기초연금·장애수당 등) 상세페이지로 바로 연결하는 딥링크는 복지로 측에서 공식 제공하지 않아, 목록 페이지 진입 후 사이트 내 검색을 이용해야 합니다.

공공데이터포털 복지 API 실시간 조회 백엔드 프록시 경유

인증키는 이 페이지가 아니라 서버(.env)에만 보관됩니다. 아래 버튼은 우리 서버의 /api/welfare/list를 호출하고, 서버가 대신 data.go.kr에 요청합니다.

※ 오류가 뜨면 서버 콘솔(node server.js를 실행한 터미널)에 더 자세한 로그가 남습니다. .env의 WELFARE_LIST_PATH가 마이페이지에서 확인한 실제 경로와 일치하는지 먼저 확인하세요.

진짜 데이터로 연동하려면 준비할 것

보고서 5장(인허가) 기준, 1단계 착수 시 필요한 준비물입니다.

  1. data.go.kr 회원가입 — 공공데이터포털에 개인 또는 사업자로 가입합니다.
  2. 복지 API 활용신청 — '한국사회보장정보원_중앙부처복지서비스', '한국사회보장정보원_지자체복지서비스'를 검색해 각각 활용신청합니다. 개발계정은 대부분 자동승인이며 바로 인증키가 발급됩니다.
  3. 정확한 요청 규격 확인 — 승인 후 상세페이지의 Swagger 문서에서 실제 요청주소·파라미터를 확인합니다(기관 사정으로 URL이 바뀔 수 있어, 이 데모의 요청 URL은 그대로 신뢰하지 말고 반드시 재확인하세요).
  4. CORS 우회용 백엔드 — 브라우저 직접 호출이 막히면, 가벼운 서버리스 함수(예: Cloudflare Workers, Vercel Functions) 하나를 프록시로 두고 그 뒤에서 인증키를 안전하게 보관합니다.
  5. 은행·마이데이터 데이터가 필요해지는 2단계부터 — 코드에프(CODEF) 같은 이미 마이데이터 허가를 보유한 데이터 중개 플랫폼 구독을 검토합니다. 본인신용정보관리업 정식 허가(자본금 5억 원 이상)는 트랙션 확인 후 단계입니다.
이 데모는 판매·인가된 서비스가 아니며, 전략 보고서 검증을 위한 프로토타입입니다.
